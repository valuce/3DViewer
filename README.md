# 3DViewer

Быстрый и лёгкий просмотрщик 3D-моделей для Windows на Rust.
Один exe (~11 МБ), без зависимостей, окно появляется мгновенно, модель грузится в фоне.

## Форматы

| Формат | Что читается |
|---|---|
| glTF / GLB | меши, узлы и трансформации, PBR-материалы, текстуры (встроенные и внешние), вершинные цвета, анимации/скины/морфы (информация) |
| FBX | через [ufbx](https://github.com/ufbx/ufbx): меши, материалы, встроенные и внешние текстуры, анимации, кости |
| OBJ + MTL | через ufbx |
| STL | бинарный и ASCII, цвета VisCAM/SolidView |
| PLY | ASCII, binary LE/BE, меши и облака точек, Gaussian splat (цвет из SH DC), `TextureFile` |
| 3MF | ядро, base materials, color groups, компоненты, расширение production (Bambu Studio, Prusa, Orca) |
| OFF | OFF / COFF / NOFF |

## Режимы отображения

Материалы (PBR), глина, без света, нормали, UV-шахматка, цвета вершин, каркас (со скрытием невидимых линий), точки.
Переключатели: рёбра поверх модели, текстуры, плоское затенение, цвета вершин, отсечение задних граней,
сетка, оси, габаритный бокс, перспектива или ортогональная проекция, ось вверх Y или Z.

## Информация о модели

Формат, размер файла, время чтения и выгрузки в GPU, память GPU, вершины и треугольники, меши
(с переключением видимости и подсветкой при наведении), материалы, текстуры с разрешением, габариты,
узлы, анимации, кости, морфы, предупреждения загрузчика. Сводку можно скопировать в буфер обмена.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | вращать |
| ПКМ / СКМ / Shift+ЛКМ | сдвигать |
| Колесо | приближать |
| Двойной клик, F | показать целиком |
| 1 … 8 | режимы отображения |
| W / T / L / V / C | рёбра / текстуры / плоско / цвета вершин / отсечение |
| G / X / B | сетка / оси / габариты |
| P / U | орто / ось Z вверх |
| Ctrl+1 / 3 / 7 / 9 | спереди / справа / сверху / снизу |
| PgUp / PgDn, ← / → | предыдущий / следующий файл в папке |
| Ctrl+O, F5, F11, F1 | открыть, перезагрузить, полный экран, справка |

Файл можно открыть перетаскиванием в окно или аргументом командной строки (подходит для ассоциации файлов):

```
viewer3d.exe model.glb
viewer3d.exe --info a.fbx b.stl     # сводка в консоль без окна
```

## Сборка

Нужны Rust (stable, MSVC) и Visual Studio Build Tools (компилятор C для ufbx).

```
cargo build --release
cargo test
```

Готовый exe: `target\release\viewer3d.exe`.

## Устройство

- `src/loaders/*` — загрузчики форматов, все выдают общий `Scene` (`src/scene.rs`).
- `src/render/*` — рендер на wgpu (DX12/Vulkan): MSAA 4×, PBR с тональной кривой Khronos Neutral,
  normal maps без тангенсов, мипмапы на GPU, каркас через `PolygonMode::Line`, точки инстансами.
- `src/app.rs`, `src/ui.rs` — окно, камера, панели на egui/eframe.
