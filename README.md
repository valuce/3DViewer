# 3DViewer

<img src="assets/icon_256.png" width="96" align="right" alt="">

Быстрый и лёгкий просмотрщик 3D-моделей для Windows на Rust.
Один exe (~12 МБ) без зависимостей и установки. Окно появляется мгновенно, модель грузится в фоне,
в простое процессор не нагружается.

*Fast, lightweight 3D model viewer for Windows written in Rust. Single portable exe, Russian and English UI.*

## Скачать

Готовая сборка — на странице [Releases](../../releases): `viewer3d.exe` можно запускать сразу.

## Форматы

| Формат | Что читается |
|---|---|
| glTF / GLB | меши, иерархия узлов, PBR-материалы, текстуры, цвета вершин, **анимации, скины, морфы**; сжатие **Draco** и **meshopt**, квантование (KHR_mesh_quantization), KHR_texture_transform |
| FBX | через [ufbx](https://github.com/ufbx/ufbx): меши, материалы, текстуры (встроенные и внешние), **анимации, скины, blend shapes** |
| OBJ + MTL | через ufbx |
| COLLADA (DAE) | геометрия всех типов примитивов, иерархия, контроллеры skin/morph, материалы profile_COMMON и текстуры |
| 3DS | объекты, материалы, текстуры, группы сглаживания |
| BLEND | файлы Blender 2.8–5.x (в т. ч. сжатые): меши, UV, материалы, трансформации объектов; модификаторы не применяются |
| STL | бинарный и ASCII, цвета VisCAM/SolidView |
| PLY | ASCII и binary, меши и облака точек, Gaussian splat (цвет из SH DC) |
| 3MF | ядро, base materials, color groups, компоненты, расширение production (Bambu Studio, Prusa, Orca) |
| OFF | OFF / COFF / NOFF |

## Возможности

- **Режимы отображения:** материалы (PBR), глина, без освещения, нормали, UV-шахматка, цвета вершин,
  каркас со скрытием невидимых линий, точки.
- **Переключатели:** рёбра поверх модели, текстуры, плоское затенение, цвета вершин, отсечение задних граней,
  сетка, оси, габаритный бокс, ортогональная проекция, ось Z вверх.
- **Анимация:** пуск/пауза, выбор клипа или все клипы сразу, перемотка, скорость, повтор.
- **Фон:** пресеты, сплошной цвет или градиент из двух цветов.
- **Информация о модели:** формат, время чтения и выгрузки в GPU, память GPU, вершины и треугольники,
  список мешей с видимостью и подсветкой, материалы, текстуры с разрешением, габариты, узлы, анимации,
  кости, морфы, предупреждения загрузчика; сводку можно скопировать.
- **Ассоциации файлов:** «Файл → Ассоциации файлов…» добавляет 3DViewer в «Открыть с помощью»
  для всех форматов (без прав администратора). То же из командной строки: `viewer3d.exe --register`
  (`--unregister` — убрать).
- Интерфейс на русском и английском (по умолчанию — язык системы).

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | вращать |
| ПКМ / СКМ / Shift+ЛКМ | сдвигать |
| Колесо | приближать |
| Двойной клик, F | показать целиком |
| 1 … 8 | режимы отображения |
| W / T / L / V / C | рёбра / текстуры / плоско / цвета вершин / отсечение |
| G / X / B | сетка / оси / габариты |
| P / U | орто / ось Z вверх |
| Ctrl+1 / 3 / 7 / 9 | спереди / справа / сверху / снизу |
| Пробел | пуск / пауза анимации |
| PgUp / PgDn, ← / → | предыдущий / следующий файл в папке |
| Ctrl+O, F5, F11, F1 | открыть, перезагрузить, полный экран, справка |

Файл открывается перетаскиванием в окно или аргументом командной строки:

```
viewer3d.exe model.glb
viewer3d.exe --info a.fbx b.stl     # сводка в консоль без окна
```

## Сборка

Нужны Rust (stable, MSVC) и Visual Studio Build Tools (компилятор C/C++ для ufbx и meshoptimizer).

```
cargo build --release
cargo test
```

Готовый exe: `target\release\viewer3d.exe`.

## Устройство

- `src/loaders/*` — загрузчики форматов, все выдают общий `Scene` (`src/scene.rs`).
- `src/anim.rs`, `src/player.rs` — узлы, клипы, скиннинг и морфы на CPU, проигрывание.
- `src/render/*` — рендер на wgpu (DX12/Vulkan): MSAA 4×, PBR с тональной кривой Khronos Neutral,
  normal maps без тангенсов, мипмапы на GPU, каркас через `PolygonMode::Line`, точки инстансами.
- `src/app.rs`, `src/ui.rs`, `src/i18n.rs` — окно, камера, панели на egui/eframe, локализация.
- `src/assoc.rs` — ассоциации файлов в реестре текущего пользователя.
