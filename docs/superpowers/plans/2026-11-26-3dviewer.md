# 3DViewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fast, lightweight Windows 3D model viewer in Rust with many formats, display modes and model info.

**Architecture:** eframe (wgpu-only) app. Loaders turn files into a format-neutral `Scene` on a background thread;
`render::Renderer` uploads it to a `GpuScene` and draws into an offscreen MSAA texture shown as an egui image.
egui panels show info and settings.

**Tech Stack:** Rust stable (msvc), eframe/egui-wgpu 0.37, wgpu (version pinned by egui-wgpu), glam, gltf, ufbx, image, zip, quick-xml, rfd, memmap2, bytemuck.

**Spec:** `docs/superpowers/specs/2026-11-26-3dviewer-design.md`

## Global Constraints

- Windows x86_64 MSVC; single exe; release profile: `lto = "fat"`, `codegen-units = 1`, `strip = true`, `panic = "abort"`.
- Formats: glTF/GLB, OBJ+MTL, STL (ascii/binary), PLY (ascii/binary LE/BE), FBX, 3MF, OFF.
- Reactive repaint only (no continuous redraw when idle).
- Loading never blocks the UI thread; errors shown in UI, never panic.

## Review Focus

1. Huge meshes (10M+ triangles, 100M+ STL bytes) — loaders must be linear-time, no per-vertex hashing; u32 indices.
2. Missing data — no normals / no UVs / no materials / no faces (point cloud) must render, not crash.
3. Broken or truncated files — return `Err` with message (binary STL with wrong count, PLY header garbage).
4. Textures referenced by path that don't exist / embedded images — load what exists, warn about the rest.
5. Degenerate bounds (single point, empty scene) — camera framing must not produce NaN.

Each is pinned by a test in the owning loader task (truncated input, no-normals input, single-point bounds).

## Interfaces (shared)

```rust
// scene.rs
pub enum Topology { Triangles, Lines, Points }
pub struct Mesh { pub name: String, pub positions: Vec<[f32;3]>, pub normals: Vec<[f32;3]>,
  pub uvs: Vec<[f32;2]>, pub colors: Vec<[u8;4]>, pub indices: Vec<u32>, pub topology: Topology,
  pub material: Option<usize>, pub had_normals: bool }
pub struct Material { pub name: String, pub base_color: [f32;4], pub metallic: f32, pub roughness: f32,
  pub emissive: [f32;3], pub base_color_tex: Option<usize>, pub normal_tex: Option<usize>,
  pub mr_tex: Option<usize>, pub occlusion_tex: Option<usize>, pub emissive_tex: Option<usize>,
  pub double_sided: bool, pub alpha_mode: AlphaMode }
pub struct TextureData { pub name: String, pub width: u32, pub height: u32, pub rgba: Vec<u8> }
pub struct Aabb { pub min: Vec3, pub max: Vec3 }  // Aabb::empty(), extend(), is_valid(), center(), size()
pub struct SceneInfo { pub format: String, pub file_size: u64, pub load_ms: f64, pub nodes: usize,
  pub animations: Vec<String>, pub skins: usize, pub bones: usize, pub cameras: usize, pub lights: usize,
  pub morph_targets: usize, pub up_axis_z: bool, pub warnings: Vec<String>, pub extra: Vec<(String,String)> }
pub struct Scene { pub meshes: Vec<Mesh>, pub materials: Vec<Material>, pub textures: Vec<TextureData>,
  pub info: SceneInfo }  // Scene::bounds() -> Aabb, Scene::finalize() fills missing normals
pub fn compute_normals(positions: &[[f32;3]], indices: &[u32]) -> Vec<[f32;3]>  // area-weighted
```

## Tasks

### Task 1: Scaffold + scene model
- [ ] Cargo.toml deps + release profile; `scene.rs` with types above; tests: `compute_normals` of a unit quad gives +Z;
      `Aabb::empty().is_valid() == false`; single-point bounds center finite. Commit.

### Task 2: Simple-format loaders (STL, PLY, OFF, 3MF) + dispatch
- [ ] Tests first per format: binary STL 1 triangle → 3 verts, 1 tri, normals from facet; ascii STL; truncated binary STL → Err;
      PLY ascii cube w/o normals → 8 verts 12 tris, normals generated; PLY binary LE with colors; PLY vertices only → Topology::Points;
      OFF triangle+quad → 3 tris; 3MF zip built in-test with 1 triangle and item transform → transformed positions.
- [ ] Implement parsers (own, linear time, STL via bytemuck-free LE reads). Dispatch by extension, STL ascii/binary by size check.
- [ ] Run `cargo test`, commit.

### Task 3: glTF + ufbx loaders + parallel image decode
- [ ] Test: in-memory minimal GLB (one triangle, no normals) → 1 mesh, 3 verts, normals generated.
- [ ] Implement gltf node traversal with baked transforms (normals via inverse-transpose), materials, texture refs,
      animations/skins info; ufbx for .fbx/.obj with triangulation, materials, file textures; images decoded on threads.
- [ ] Manual check on real files (user GLBs from TRELLIS). Commit.

### Task 4: Renderer
- [ ] GpuScene upload (interleaved vertex 36 B: pos, normal, uv, rgba8), textures sRGB/linear + GPU mips,

- [ ] mesh.wgsl: modes Shaded/Clay/Unlit/Normals/UvChecker/VertexColor, flat shading + normal map via derivatives;
      wire pipeline (PolygonMode::Line, feature-gated), points pipeline (instanced quads), lines pipeline (grid/axes/bbox).
- [ ] Run app on test files, commit.

### Task 5: App + UI

- [ ] Menus, toolbar, info panel, mesh visibility list, status bar, drag&drop, CLI path, recent files, PgUp/PgDn folder browse,
      background loading with spinner, settings persistence.
- [ ] Release build, measure exe size + startup, commit, push.
